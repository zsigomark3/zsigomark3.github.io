Projects

I could write novels about my projects and failed attempts. Instead of just talking about them, dive into the world of my projects, each a unique journey of creativity and problem-solving.

Flashing my first modded Android

Xperia X8, 2012. I will never forget how happy I was. FroyoBread, then GingerBread...This is how it all started, and I've been using custom ROMs ever since (LineageOS).

Flashing OpenWrt first time

In 2016 I decided to take full control over my router. It was a Linksys WRT1900ACS - I immediately felt the boost it brought. I have been using only OpenWrt ever since.

My first crypto mining

In 2017, I tried my VGA AMD R9 280 on ETHash it made 12,2MH/s. I mined 0.01 ETH in 24 hours (244 shares). Shortly afterward, I built my first complete mining rig of 6x RX580 GPU's.

Building my own website

I began working on my website in 2018, motivated by curiosity and a desire to learn through hands-on experimentation rather than to showcase a portfolio.

Building my own home network

2020. It started with a Pi-Hole, a custom DNS server what got evolved into a home server of NAS, with Grafana and Prometheus monitoring, a self hosted VPN and Nextcloud, Arr stack, Home assistant...

Dealing with test automation

2024 I learned, then I had opportunity to try BDD test automation framework, where Java drives the test logic, Selenium WebDriver handles browser automation for UI testing, and Cucumber provides the BDD layer using Gherkin feature files.
